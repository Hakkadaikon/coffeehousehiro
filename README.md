# コーヒーhouseヒロ ランディングページ

岡山県倉敷市の週末限定ロースター「コーヒーhouseヒロ」の公式ランディングページです。
ReactとViteで作った1ページだけの静的サイトで、https://coffeehousehiro.vercel.app/ で公開しています。

## 動かし方

Node.js 24で動かします。

```bash
npm ci
npm run dev    # http://localhost:3000 で開発サーバーが起動する
npm test       # テスト
npm run build  # dist に本番用のファイルを書き出す
```
